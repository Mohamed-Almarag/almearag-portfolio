# almearag-portfolio

Personal portfolio of Mohamed Almearag, Senior Frontend Engineer.

**Live:** [almearag-portfolio.vercel.app](https://almearag-portfolio.vercel.app)

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS, deployed on Vercel.

## Development

```bash
pnpm install
pnpm dev
```

| Script           | Purpose                          |
| ---------------- | -------------------------------- |
| `pnpm lint`      | ESLint                           |
| `pnpm typecheck` | Generate route types and run tsc |
| `pnpm format`    | Format with Prettier             |
| `pnpm build`     | Production build                 |

Commits follow [Conventional Commits](https://www.conventionalcommits.org) and are checked by Lefthook and commitlint.
